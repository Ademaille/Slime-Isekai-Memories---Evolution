✨ Fonctionnalités Principales

👥 Gestion des Duos & Équipes :

Attribution d'un nom d'équipe personnalisable directement dans le tableau

Furie Élé / Ultime (120/150) : Suivi sur 5 colonnes (6 à 10) par personnage

Niveaux de Compétence : Fenêtre interactive pour attribuer un niveau de 1 à 9 ou MAX (x)

Compteur global des duos enregistrés
